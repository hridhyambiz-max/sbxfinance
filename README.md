# SBX Finance — GitHub Pages Build v2.33.3

Upload **all four items from this folder** to the repository root:

- `index.html`
- `firebase-config.js`
- `.nojekyll`
- `README.md` (optional for the website, useful for reference)

GitHub Pages settings:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

After deployment, open the Pages URL rather than the GitHub code URL.
The first load performs a one-time cleanup of stale service-worker/cache entries for this build.

For Firebase Authentication, add the GitHub Pages hostname to Firebase Console → Authentication → Settings → Authorized domains.
Example hostname: `hridhyambiz-max.github.io`
